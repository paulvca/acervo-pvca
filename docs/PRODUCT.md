# Produto

## Objetivo

Transformar o Acervo PVCA em um site pessoal de cinema: um catálogo navegável, editorial e público, alimentado por uma base privada mais rica.

## Face pública

Navegação principal:

- Início
- Filmes
- Seleções
- Sobre

## Face privada

Administração, inventário, QA, sincronização, publicação e outros estados operacionais são uma camada separada. O primeiro release público não depende de um painel administrativo.

## Tom

O site deve parecer um acervo pessoal mantido por uma pessoa, não um dashboard corporativo ou catálogo genérico.
